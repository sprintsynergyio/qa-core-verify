Private, internal review build. Not released. This page is for a reviewer inside the team. It is not a release note.

Version in `package.json` is `0.1.0`. `"private": true` stays set. Do not tag, publish, or change repository visibility from this review.

## What To Run

From a fresh clone, on Node.js 22.6 or later:

```sh
PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 npm ci
npm run typecheck
npm test
npx playwright install chromium
node dist/cli.js example-project/saucedemo
QCV_LIVE=1 npm test
node dist/cli.js example-project/saucedemo --only locator
node dist/cli.js example-project/saucedemo --only faults
node dist/cli.js example-project/saucedemo --only inversion
```

`npm test` does not call SauceDemo. `QCV_LIVE=1 npm test` does. The three `node dist/cli.js` commands after that also call SauceDemo. Run each of those three times when you are checking that a live run repeats.

That is the live site, not a passing check. The stderr line names the test and, for a control run, the first Playwright error line. Run that command again before treating the row as a product defect.
