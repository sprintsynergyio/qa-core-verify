# v0.1 Review

Private, internal review build. Not released. This page is for a reviewer inside the team. It is not a release note.

Version in `package.json` is `0.1.0`. `"private": true` stays set. Do not tag, publish, or change repository visibility from this review.

## What To Run

From a fresh clone, on Node.js 22.6 or later:

```sh
PLAYWRIGHT_SKIP_BROWSER_DOWNLOAD=1 npm ci
npm run typecheck
npm test
npx playwright install chromium
node dist/cli.js example-project/saucedemo
QCV_LIVE=1 npm test
node dist/cli.js example-project/saucedemo --only locator
node dist/cli.js example-project/saucedemo --only faults
node dist/cli.js example-project/saucedemo --only inversion
```

`npm test` does not call SauceDemo. `QCV_LIVE=1 npm test` does. The three `node dist/cli.js` commands after that also call SauceDemo. Run each of those three times when you are checking that a live run repeats.

The static sample in the README was copied from `node dist/cli.js example-project/saucedemo` on 2026-11-14. The summary line was:

```text
Summary: 9 trusted, 3 review, 6 untrusted, 0 baseline-red, 1 not-run. 6 errors, 3 warnings, 3 info findings.
```

Exit code was 1. Locator and cannot-fail checks did not run.

## What Each Check Should Show

Static, on `example-project/saucedemo`:

- `tests/good` has no warn or error. Those four tests are trusted.
- The seeded weak assertions in `tests/ai-style/weak-assertions.spec.ts` match `expected-findings.json` where `status` is `active`.
- QCV-F002 and QCV-F003 are `pending` in that file. The static command does not report them.
- One test is `not-run`: `skipped inventory check`, with QCV-W009.
- Summary: 9 trusted, 3 review, 6 untrusted, 0 baseline-red, 1 not-run. 6 errors, 3 warnings, 3 info findings.

Locator, inversion, and faults open a browser against https://www.saucedemo.com. A slow response can make one baseline or one control run `baseline-red` or print `Control run did not pass`. That is the live site, not a passing check. The stderr line names the test and, for a control run, the first Playwright error line. Run that command again before treating the row as a product defect.

QCV-F004 warns when a test stays green under every fault other than `blank-app`, and the run had at least one such fault. `does not read the page` is untrusted with QCV-F002, QCV-F003, and QCV-F004. A test in `tests/good` that fails `blank-app` and passes every other fault is `review` because of QCV-F004. `skipped inventory check` is `not-run`, and each fault cell for it is `skipped`.
